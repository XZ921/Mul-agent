# 分析规则
1. featureComparison、positioningComparison、targetUserComparison 是阶段1首报核心分析字段；如果证据充分必须输出，不能只写 overview。
2. pricingComparison、strengthsSummary、weaknessesSummary 是阶段1增强分析字段；如果证据不足可以返回 null 或空字符串，但不要编造。
3. 每个分析字段都必须基于竞品数据中的 sourceUrls、evidenceCoverage、downstreamEvidenceViews 或 structuredBlocks。
4. sourceUrls 只能使用竞品数据中已经出现的来源链接，禁止生成新 URL。
5. 如果某个维度缺少证据，请把对应字段留空，并在 issueFlags 中显式写出缺口，不要假装完整。
6. overview 不能替代 featureComparison、positioningComparison、pricingComparison、targetUserComparison、strengthsSummary、weaknessesSummary。
7. 输出必须是 JSON 对象，不要输出 Markdown、解释文字或模型元话术。
